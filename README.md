# Algorithm Problem Solving Training

This project is developed to practice and improve algorithm problem-solving skills, ranging from simple to complex challenges. Each file in the `src` directory contains solutions to different algorithmic problems, implemented in TypeScript.

## Structure

- `src/` — Contains TypeScript files for various algorithm problems (e.g., palindrome check, string reversal, etc.)
- `run.ts` — Entry point or runner script (if applicable)

## Purpose

The main goal is to enhance algorithmic thinking and coding proficiency by solving a variety of problems and experimenting with different approaches.

---

Feel free to explore, modify, and add new problems as you continue your learning journey!

## Copilot Usage Instructions

This project is set up for algorithm problem-solving in TypeScript. To get the most out of GitHub Copilot:

- Use Copilot to generate, refactor, or optimize solutions for each algorithm problem in the `src/` directory.
- When working on a new problem, start by describing the problem in a comment at the top of your file. Copilot will use this context to suggest relevant code.
- For best results, write clear function signatures and descriptive variable names.
- You can ask Copilot for explanations, alternative solutions, or optimizations directly in your code comments.
- If you want Copilot to ignore a region, use comments like `// copilot: disable` and `// copilot: enable` (if supported by your Copilot version).

### Example Workflow

1. Create a new file in `src/` for your algorithm problem.
2. Add a comment describing the problem.
3. Start writing the function signature; Copilot will suggest code based on your context.
4. Review, test, and refine the solution as needed.
